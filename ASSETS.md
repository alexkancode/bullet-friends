# Asset Licenses

All sprites in `packages/client/public/art/` are original vector art created
for this project and released under CC0 1.0 (public domain). No third-party
art is bundled. Typography uses the viewer's system UI font stack; no font
files ship with the game.

All audio in `packages/client/public/audio/` is likewise original, generated
deterministically by `tools/generate-audio.mjs`, and released under CC0 1.0.
Regenerate any of it by running `node tools/generate-audio.mjs`.
